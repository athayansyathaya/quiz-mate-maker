PLAGIX – Figma Mockup Pack

Buka tiap halaman di bawah, lalu import ke Figma menggunakan plugin html.to.design.

Cara import ke Figma:

  1. Buka Figma desktop, install plugin html.to.design dari Plugins → Browse plugins.
  2. Buka tiap file di browser (klik link di bawah). Salin URL file://... atau buka file lokalnya.
  3. Plugin → html.to.design → tab "URL" → paste URL, atau gunakan tab "Upload" → upload .html-nya.
  4. Plugin akan generate frame Figma yang bisa kamu edit.
