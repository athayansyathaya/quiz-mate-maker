📐 Cara Import ke Figma

  1. Buka Figma → menu Plugins → Browse all plugins → cari & install "html.to.design"
  2. Jalankan project ini lokal: buka folder portfolio-figma/ lalu serve, contoh:
    npx serve portfolio-figma → akan muncul URL http://localhost:3000
  3. Di Figma, jalankan plugin html.to.design → pilih tab URL → paste http://localhost:3000/01-home.html → klik Import
  4. Ulangi untuk 02-about.html, 03-portfolio.html, 04-contact.html
  5. Setiap halaman akan menjadi frame Figma terpisah, siap di-edit & dijadikan prototype (hubungkan tombol navigasi antar frame via mode Prototype)

💡 Alternatif tanpa serve: buka langsung index.html di browser → klik tiap halaman, lalu Save Page As → Webpage Complete, dan di plugin pilih tab Upload untuk mengunggah file HTML-nya.
